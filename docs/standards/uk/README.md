# Українські робочі переклади

Неофіційні машинні переклади. Повну технічну редактуру не виконано. Кожен документ перекладається та зберігається окремо перед переходом до наступного.

Формули, складні таблиці й рисунки збережено як зображення у складі сторінок оригіналу. Після кожного зображення наведено український переклад відповідної сторінки. Написи всередині зображень залишено мовою оригіналу. OCR та машинний переклад можуть містити помилки; формули й числа слід звіряти із зображенням.
