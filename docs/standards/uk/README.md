# Українські робочі переклади

Неофіційні робочі переклади; незалежну технічну редактуру не виконано. Кожен документ опрацьовується окремо. До наступного документа переходимо після завершення поточного.

S01 та S02 створено із застосуванням зовнішнього машинного перекладача. S03 перекладається безпосередньо в ChatGPT без зовнішнього сервісу перекладу.

Формули та складні таблиці вставляються зображеннями. У S03 формули відтворено відповідно до оригіналу, таблиці перекладено українською та відтворено зображеннями. Зображення відповідних сторінок оригіналу також збережено для звіряння. Написи всередині оригінальних рисунків залишаються англійською; переклад підписів подано окремо. Числові значення й позначення слід звіряти з оригіналом.
