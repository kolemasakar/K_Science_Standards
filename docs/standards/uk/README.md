# Українські робочі переклади

Неофіційні робочі переклади; незалежну технічну редактуру не виконано. Кожен документ опрацьовується окремо. До наступного документа переходимо після завершення поточного.

S01 та S02 створено із застосуванням зовнішнього машинного перекладача. S03 перекладено безпосередньо в ChatGPT без зовнішнього сервісу перекладу.

Формули та складні таблиці вставляються зображеннями. У S03 формули відтворено відповідно до оригіналу, таблиці перекладено українською та відтворено зображеннями. Зображення відповідних сторінок оригіналу також збережено для звіряння. Написи всередині оригінальних рисунків залишаються англійською; переклад підписів подано окремо. Числові значення й позначення слід звіряти з оригіналом.

S03: переклад охоплює всі 86 сторінок наданої копії, включно з бібліографією та додатком. Позначені неточності оригіналу не виправлялися мовчки. S13 — README українською, переклад не потрібний. S14: опрацьовано всі 353 сторінки оригіналу; український PDF містить 431 сторінку. Формули та складні таблиці подано зображеннями, предметний покажчик перекладено зі збереженням номерів сторінок оригіналу. Бібліографічні записи збережено мовою публікацій. Посилання на нормативи відповідають історичному виданню 2006 року. S15: перекладено всі 52 сторінки, зокрема британський національний додаток; український PDF має 59 сторінок. Позначено розбіжності оригіналу щодо допуску довжини керна, посилання NA.5.5 та знака у формулі (NA.1). S16: підготовлено редаговану українську DOCX-версію перекладу S15 того самого видання. Позначення й структура вихідних копій збігаються; повну покомпонентну тотожність PDF і DOCX не встановлено. Наступний документ: S17, лабораторний посібник lab_manual_hardened_Full.pdf, 190 сторінок.
